title: Setting up a new domain
summary: Everything from creating the domain to going live, in order.
order: 5
---

A domain is a program area, for example Backend or Fullstack. Each domain has its own modules, team assignments, settings and status. Nothing is sent while a domain is a **Draft**.

![The domain details](/help/domains-drawer.png)

1. Open [Domains](/setup/domains) and press **Create domain**. To start from another domain's settings, choose it under **Copy settings from another domain**.
2. Choose the domain's Discord server on [Connections](/settings/connections), then open the domain and choose its **Alert channel** (where the team is tagged). See [Discord](/help/discord).
3. Choose **Escalation contacts**: they get told when an urgent problem is not fixed in time.
4. Choose the **Default operations team**: they handle class tasks, failed messages and written replies.
5. Check the **Class types** (for example Live class and Office hours) and add any **Holidays**.
6. Add the modules: see [Setting up a module](/help/setting-up-a-module).
7. Add or check the instructors: see [Adding and checking instructors](/help/instructors).
8. Plan classes: see [Planning classes and cohorts](/help/planning-classes).
9. Turn on testing and run a practice class: see [Testing safely and going live](/help/testing-and-going-live).
10. When everything works, go live.

> Home shows a setup checklist for a domain that is not ready yet. Each item links to the page where you fix it.
