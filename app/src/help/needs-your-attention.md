A **task** is something the automation could not finish by itself, for example nobody left to ask, a written reply from an instructor, a message that could not be delivered, or class tasks that are overdue. Tasks are on [Home](/), urgent ones first.

![Tasks on Home](/help/home-tasks.png)

1. Read the task. It says what happened and which class it is about.
2. Press **I'm on it** so the team knows you are handling it. Reminders about it pause for a day.
3. Do what is needed. The buttons help: **Assign and confirm instructor**, **Open class**, **Open help request** or **Reply**.
4. Press **Mark done** when it is finished, with a short note if useful.

## Hand a task to someone else

Choose a person under **Assign to**. They are tagged and reminded instead of you.

## Reminders and escalation

If a task stays open, the people it is for are reminded. If it is still open after a while, the escalation contacts are told. Urgent tasks are reminded more often.

> Use the filters to see only urgent tasks, only your tasks, or tasks done in the last 7 days. The filters only show when there are tasks.
