## Nobody is being asked for a class week

1. Open the class week. If it says **Setup not finished**, the setup check found a problem; the task on Home says what.
2. If it says **Not started yet**, asking starts later (30 days before by default). Press **Start asking now** to start today.
3. If it says **Needs an instructor**, everyone in the order said no or could not be asked. Add instructors to the order or use **Ask a specific person**.

## An instructor is skipped

Open **Who we ask next** on the module page. It shows the reason for each person, for example not available that day, already teaching at that time, or contact details not checked.

## A message was not delivered

A task tells you exactly what to fix, for example a channel that no longer exists or a username that was not found. Fix it, then open the class week and press **Send last message again**.

## I can't sign in

Use your company Google account. During the beta, only people on the beta list can sign in: ask an admin to add you on Settings, Admin. If you were removed from the team, ask a colleague to give your access back on the Team page.

## The Connections page

![Connections](/help/connections.png)

Each line shows a status:

- **Working:** the last message went out.
- **Ready, no messages yet:** set up, but nothing has been sent yet. This is normal after setup; nothing is wrong.
- **Not set up:** a step is missing. The line says which one.
- **Problem:** the last attempt failed after the last message that went out. The line says what failed and what to fix.

Admins see **Send a test** on Discord and Email. Discord posts a test to the admin alert channel; Email sends one to your own address. Each test is in Activity history. Use it to check both work in one click, for example after a change.

**Errors in the app** lists problems people ran into while using the app. If you see the same error many times, tell whoever looks after the app.

**Advanced: links** shows the sender email and two links. The links are set by whoever installs the app and cannot be changed here.

## Still stuck

Look in [Activity history](/activity) for what happened last, and ask in your team's Discord channel.
