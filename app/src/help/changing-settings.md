title: Changing settings for a cohort, module or class week

Settings decide when instructors are asked, how long they have to reply, when reminders go out and more. A setting can be changed for the whole domain, and also only for one cohort, one module or one class week. The most specific one wins: a class week beats its module, a module beats its cohort, and a cohort beats the domain.

![Automation settings](/help/automation.png)

## Change a setting

1. Open [Automation](/settings/automation).
2. Under **Settings for**, choose the whole domain, a cohort or a module. For one class week, open the class week on Upcoming classes and press **Change settings for this class week only**.
3. Change the values. Each field shows where its value comes from, for example **From domain settings** or **Changed for this cohort**.
4. Press **Save changes** in the bar at the bottom. For a cohort, module or class week you can add a reason; it goes into Activity history.

To undo your own value, press **Use the value above** (or **Reset to default** for the domain).

## Timing in one click

On the **Requests and timing** tab, choose **Standard**, **Relaxed** or **Strict**, then press **Save changes**. The exact numbers are under **Advanced**.

Changes apply to everything not yet sent. Nothing already sent is repeated.

## Message texts

1. Open [Message templates](/settings/messages) and choose a message.
2. Change the text. Details in braces, like {module} or {classes}, are filled in when the message is sent. The list under **Details you can use** shows them all.
3. Watch the **Preview**. If something required is missing, you see it in red.
4. Press **Send test message** to see it in your alert channel, then **Save changes**.
5. **Reset to default** brings back the original text.

## Class tasks and help requests

- The default tasks for every class are on the **Before class** tab. Extra tasks for one class can be added in that class week.
- Who gets each kind of help request is on the **Help and follow up** tab.
